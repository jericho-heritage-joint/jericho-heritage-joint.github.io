決済

決済したのに商品が届きません。

決済が完了する前にゲームが閉じた場合は、次にゲームを起動したときに自動で付与されます。ゲームを完全に終了してから、もう一度起動してみてください。それでも届かない場合は、Appleのレシートに記載された注文番号を添えてお問い合わせください。

「保護者の承認を待っています」と表示されます。

ファミリー共有の「承認と購入のリクエスト」がオンになっている場合は、保護者が承認してはじめて決済されます。承認されると、ゲーム内ですぐに受け取れます。

「このデバイスでは購入が制限されています」と表示されます。

iPhoneの設定 → スクリーンタイム → コンテンツとプライバシーの制限 → iTunesおよびApp Storeでの購入で、「App内課金」が許可されているかをご確認ください。

返金（申込みの撤回）をしたいです。

  • App Storeで決済した商品の返金は、Appleが処理します。 reportaproblem.apple.comからリクエストできます。
  • 購入後7日以内で、付与された商品をまったく使っていない場合は、申込みの撤回を求めることができます。
  • 一部でも使用した商品、期間特典がすでに始まっている商品（森の小道パス、月間金のリンゴ、広告削除）は、申込みの撤回が制限されます。
  • 返金されると、付与された商品は回収されます。
  • 未成年者が法定代理人の同意なく決済した場合は、本人または法定代理人が取消しを求めることができます。

ランダムで出る商品の確率はどこで見られますか？

ゲーム内のショップ下部にある「提供割合」で確認できます。

購入の復元

端末を変えたら、広告削除が適用されていません。

同じApple IDでサインインしている端末なら、通常は自動で戻ります。戻らない場合は、ショップ下部の「購入を復元」をタップしてください。

金のリンゴなどの通貨やパックで受け取ったアイテムは、購入の復元ではなく、アカウントのクラウド保存で引き継がれます（下記「アカウントと保存」）。

アカウントと保存

新しい端末で続きから遊びたいです。

Game Centerにサインインした状態でプレイすると、進行状況がクラウドに保存されます。新しい端末で同じGame Centerアカウントにサインインしてゲームを起動すると、クラウドの進行状況を読み込むかどうか確認されます。「読み込む」をタップしてください。

Game Centerなしでプレイしていました。

Game Centerにサインインしていない場合、アカウントはその端末にしかないため、ほかの端末に移すことはできません。端末を変える前に、iPhoneの設定でGame Centerにサインインしてから、ゲームを起動してください。この端末の進行状況が、そのアカウントに保存されます。

クラウド保存はいつ行われますか？

進行状況が変わると数分ごとに、またゲームを終了するときに保存されます。設定 → アカウントで最後に保存した時刻を確認し、「今すぐ保存」をタップすることもできます。

アカウントを削除したいです。

設定 → アカウント → アカウント削除をタップしてください。クラウドの進行状況とこの端末の保存データがすべて削除され、元に戻すことはできません。アプリだけを削除しても、クラウドの情報は残ります。削除される情報はプライバシーポリシーに記載しています。

広告

広告報酬のボタンを押しても広告が表示されません。

広告を読み込み中か、今表示できる広告がない可能性があります。インターネット接続を確認して、しばらくしてからもう一度お試しください。

「広告削除」はどんな商品ですか？

広告を見ずに広告報酬をすぐに受け取れて、毎日金のリンゴを50個受け取れる商品です。一度購入すると、ずっと適用されます。

パーソナライズ広告をオフにしたいです。

iPhoneの設定 → プライバシーとセキュリティ → トラッキングでオフにできます。オフにしても、ゲームと広告報酬は同じようにご利用いただけます。

個人情報と通知

プレイ統計を送りたくありません。

設定 → アカウント →「プレイ統計を送る」をオフにすると、その時点から送信しません。

通知をオフにしたいです。

iPhoneの設定 → 通知 → レッサーパンダダダでオフにできます。
