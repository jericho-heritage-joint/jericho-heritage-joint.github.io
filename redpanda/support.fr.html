Paiements

J’ai payé, mais je n’ai pas reçu l’article.

Si le jeu se ferme avant la fin du paiement, l’article est remis automatiquement la prochaine fois que vous ouvrez le jeu. Essayez de quitter complètement le jeu puis de le rouvrir. S’il n’est toujours pas arrivé, contactez-nous en indiquant le numéro de commande figurant sur le reçu d’Apple.

Le message « en attente de l’accord d’un parent ou tuteur » s’affiche.

Si « Autorisation d’achat » du Partage familial est activée, le paiement n’a lieu qu’après l’accord d’un parent ou tuteur. Une fois l’accord donné, vous recevez l’article dans le jeu immédiatement.

Le message « Les achats sont restreints sur cet appareil » s’affiche.

Vérifiez que les « Achats intégrés » sont autorisés dans Réglages de l’iPhone → Temps d’écran → Restrictions relatives au contenu et à la confidentialité → Achats dans l’iTunes Store et l’App Store.

Je souhaite un remboursement (rétractation).

  • Le remboursement des articles achetés sur l’App Store est traité par Apple. Vous pouvez en faire la demande sur reportaproblem.apple.com.
  • Dans les 7 jours suivant l’achat, si vous n’avez utilisé aucun des articles remis, vous pouvez demander la rétractation.
  • La rétractation est restreinte pour les articles utilisés, même en partie, et pour les articles dont les avantages à durée limitée ont déjà commencé (Pass de la forêt, Pommes d’or mensuelles, Supprimer les pubs).
  • En cas de remboursement, les articles remis sont récupérés.
  • Si un mineur a payé sans le consentement de son représentant légal, le mineur ou son représentant légal peut demander l’annulation.

Où voir les probabilités des articles aléatoires ?

Vous les trouverez dans « Taux d’obtention », en bas de la Boutique du jeu.

Restaurer les achats

J’ai changé d’appareil et Supprimer les pubs ne s’applique plus.

Sur un appareil connecté avec le même identifiant Apple, il est généralement rétabli automatiquement. Sinon, touchez « Restaurer les achats » en bas de la Boutique.

Les monnaies comme les Pommes d’or et les objets reçus dans des packs ne sont pas transférés par « Restaurer les achats », mais par la sauvegarde dans le cloud de votre compte (voir « Compte et sauvegardes » ci-dessous).

Compte et sauvegardes

Je veux continuer sur un nouvel appareil.

Si vous jouez en étant connecté à Game Center, votre progression est sauvegardée dans le cloud. Sur le nouvel appareil, connectez-vous avec le même compte Game Center et ouvrez le jeu : il vous demandera si vous voulez charger la progression du cloud. Touchez « Charger ».

J’ai joué sans Game Center.

Si vous n’êtes pas connecté à Game Center, votre compte n’existe que sur cet appareil et ne peut pas être transféré sur un autre. Avant de changer d’appareil, connectez-vous à Game Center dans les Réglages de l’iPhone, puis ouvrez le jeu. La progression de cet appareil sera sauvegardée sur ce compte.

Quand la sauvegarde dans le cloud a-t-elle lieu ?

Toutes les quelques minutes quand votre progression change, et quand vous quittez le jeu. Dans Paramètres → Compte, vous pouvez voir l’heure de la dernière sauvegarde et toucher « Sauvegarder ».

Je veux supprimer mon compte.

Touchez Paramètres → Compte → Supprimer le compte. Votre progression dans le cloud et la sauvegarde de cet appareil sont toutes supprimées, et cette action est irréversible. Si vous supprimez uniquement l’app, les informations dans le cloud sont conservées. Les informations supprimées sont indiquées dans la Politique de confidentialité.

Publicités

J’ai touché le bouton de récompense publicitaire, mais aucune publicité ne s’affiche.

La publicité est peut-être en cours de chargement, ou aucune publicité n’est disponible pour le moment. Vérifiez votre connexion Internet et réessayez dans un instant.

Qu’est-ce que « Supprimer les pubs » ?

C’est un article qui vous permet de recevoir les récompenses publicitaires immédiatement, sans regarder de publicité, ainsi que 50 Pommes d’or chaque jour. Un seul achat suffit : l’effet est permanent.

Je veux désactiver les publicités personnalisées.

Vous pouvez les désactiver dans Réglages de l’iPhone → Confidentialité et sécurité → Suivi. Même désactivées, vous pouvez utiliser le jeu et les récompenses publicitaires exactement de la même façon.

Confidentialité et notifications

Je ne veux pas envoyer de statistiques de jeu.

Désactivez Paramètres → Compte → « Envoyer les stats de jeu », et plus rien ne sera envoyé à partir de ce moment.

Je veux désactiver les notifications.

Vous pouvez les désactiver dans Réglages de l’iPhone → Notifications → Red Pandadada.
